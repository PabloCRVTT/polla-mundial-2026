Configuración inicial

La app necesita Supabase para funcionar

Pasos para configurar (5 min):
1. Ve a supabase.com → New project
2. Project Settings → API → copia Project URL y anon key
3. Pégalos en js/config.js
4. En SQL Editor ejecuta el schema del README
5. Despliega en GitHub Pages (ver README.md)
📖 Lee el README.md para instrucciones detalladas paso a paso.
